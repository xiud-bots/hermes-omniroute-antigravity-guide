# 04.3 - Padronização para Subagentes e Perfis

Quando o Hermes cria instâncias paralelas via `delegate_task` ou quando novos perfis são criados no ecossistema, é fundamental garantir que todos herdem a rota do OmniRoute.

---

## 👥 1. Padronização Global de Subagentes (`delegation.*`)

Por padrão, os subagentes (`delegate_task`) tentam herdar as credenciais do agente pai. Para fixar o motor `Antigravity-Smart` em todas as delegações:

```bash
hermes config set delegation.model "Antigravity-Smart"
hermes config set delegation.provider "openai-api"
hermes config set delegation.base_url "http://127.0.0.1:20128/v1"
```

Isso garante que mesmo subagentes profundos (orquestradores de Kanban, avaliadores de código, scouts de pesquisa) continuem usando o pool de inteligência local do OmniRoute sem custos de API.

---

## 👥 2. Criação Padronizada de Novos Perfis

Ao criar novos perfis de agentes especializados (ex: para uma nova squad de projeto), utilize sempre a flag `--clone-from default`:

```bash
hermes profile create meu-novo-bot --clone-from default
```

Dessa forma:
- O novo bot já herda o `model.default: Antigravity-Smart`.
- O novo bot já herda o `model.base_url: http://127.0.0.1:20128/v1`.
- O novo bot já herda o `.env` com a `OPENAI_API_KEY` do OmniRoute.
