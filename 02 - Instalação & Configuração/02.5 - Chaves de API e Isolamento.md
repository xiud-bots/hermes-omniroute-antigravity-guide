# 02.5 - Emissão de Chaves de API & Segurança

O OmniRoute protege os endpoints de inferência através de chaves de API virtuais (`sk-...`). O Hermes utilizará essa chave no header HTTP padrão `Authorization: Bearer <chave>`.

---

## 🔑 1. Gerando a Chave no OmniRoute

1. Acesse o menu **API Keys** no painel do OmniRoute (`http://localhost:20128`).
2. Clique no botão **Create API Key** (ou **+ New Key**).
3. Preencha os campos:
   - **Key Name / Label:** `Hermes-Agent-Main`
   - **Model Permissions:** Selecione **All Models** ou restrinja especificamente para o combo `Antigravity-Smart`.
   - **Expiration:** *Never Expires* (ou defina conforme sua política interna de rotação).
   - **Rate Limits:** Deixe ilimitado para agentes locais.
4. Clique em **Generate Key**.
5. **Copie imediatamente o token exibido** (exemplo: `sk-7c6...449d`).

> [!WARNING]
> Assim como em provedores comerciais, a chave é mostrada integralmente apenas uma vez. Armazene-a com segurança.

---

## 🔒 2. Princípio do Menor Privilégio e Isolamento Local

No sistema Linux, a chave deve ser isolada contra leitura por outros usuários ou processos não autorizados:

1. A chave será gravada no arquivo de ambiente do Hermes: `~/.hermes/.env`
2. Aplique permissão restrita de leitura/escrita exclusiva do proprietário:
   ```bash
   chmod 600 ~/.hermes/.env
   ```
3. O OmniRoute armazena internamente os hashes criptografados com `STORAGE_ENCRYPTION_KEY` dentro de `~/.omniroute/.env`.
