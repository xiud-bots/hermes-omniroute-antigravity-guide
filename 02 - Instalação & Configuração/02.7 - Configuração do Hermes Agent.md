# 02.7 - Configuração Completa do Hermes Agent

Com o OmniRoute ativo na porta `20128` servindo o combo `Antigravity-Smart`, a etapa final é instruir o **Hermes Agent** a utilizar este endpoint local.

---

## 📥 1. Instalação do Hermes Agent

Se você ainda não possui o Hermes Agent instalado:

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

*(Ou utilize o aplicativo **Hermes Desktop** para Linux / macOS).*

---

## ⚙️ 2. Edição do `~/.hermes/config.yaml`

Abra o arquivo de configuração principal em `~/.hermes/config.yaml` (ou execute `hermes config edit`):

```yaml
# ==============================================================================
# Configuração de Modelo - OmniRoute Proxy Local
# ==============================================================================
model:
  default: Antigravity-Smart
  provider: openai-api
  base_url: http://127.0.0.1:20128/v1
  api_mode: codex_responses

# ==============================================================================
# Padronização de Subagentes (Delegação Paralela)
# ==============================================================================
delegation:
  model: Antigravity-Smart
  provider: openai-api
  base_url: http://127.0.0.1:20128/v1
  max_iterations: 250
  child_timeout_seconds: 600

# ==============================================================================
# Backend de Execução de Ferramentas
# ==============================================================================
terminal:
  backend: local
  timeout: 180
```

### Explicação dos Parâmetros Críticos:
- **`provider: openai-api`:** Informa ao Hermes que o endpoint consome o protocolo universal da OpenAI.
- **`base_url: http://127.0.0.1:20128/v1`:** Aponta diretamente para o socket local do OmniRoute.
- **`api_mode: codex_responses`:** Habilita o parse de respostas estruturadas e chunks SSE otimizados.
- **`terminal.backend: local`:** Permite que o Hermes acione binários locais no host (como `omniroute`, `systemctl`, `git`).

---

## 🔑 3. Configuração do `~/.hermes/.env`

Insira a chave de API emitida pelo OmniRoute:

```bash
# Adicionar ou substituir no ~/.hermes/.env
echo "OPENAI_API_KEY=sk-sua-chave-gerada-no-omniroute" >> ~/.hermes/.env
chmod 600 ~/.hermes/.env
```

---

## 🔄 4. Aplicação e Recarga

Para aplicar as mudanças no Hermes CLI ou Desktop:
- Se estiver com uma sessão aberta no chat, digite: `/reload` ou `/reset`.
- Se estiver rodando o Gateway Hermes: `hermes gateway restart`.
