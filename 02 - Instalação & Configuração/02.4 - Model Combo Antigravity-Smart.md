# 02.4 - Configuração do Combo `Antigravity-Smart`

Um dos recursos mais poderosos do OmniRoute é a criação de **Model Combos** — aliases que combinam múltiplos modelos com lógica avançada de roteamento, fallback e buffer de raciocínio.

---

## 🎯 Por que Criar o Combo?

Em vez de apontar o Hermes diretamente para `agy/gemini-3.8-flash-high`, criamos o combo virtual **`Antigravity-Smart`**. 
Isso garante que, se o Gemini 3.8 atingir a cota momentânea de requisições, o OmniRoute redirecionará a requisição para o Gemini 3.7 imediatamente, sem que o agente falhe ou o usuário receba erro de timeout.

---

## 🛠️ Passo a Passo no Dashboard

1. No menu lateral do OmniRoute, navegue até a aba **Combos**.
2. Clique no botão **Create Combo** (ou **Novo Combo**).
3. **Definições Gerais:**
   - **Combo Name:** `Antigravity-Smart`
   - **Routing Strategy:** `Priority` *(Chaveamento por ordem de prioridade)*
4. **Adição dos Modelos (Ordem Estrita):**
   - **1º Modelo (Prioridade Alta):**
     - Selecione: `agy/gemini-3.8-flash-high`
     - Peso (*Weight*): `0`
     - Vínculo: Selecione a conexão do seu e-mail criada no passo anterior.
   - **2º Modelo (Fallback Secundário):**
     - Selecione: `agy/gemini-3.7-flash-tiered`
     - Peso (*Weight*): `0`
     - Vínculo: Mesma conexão.
5. **Configurações Avançadas de Resiliência:**
   - **Max Retries:** `1`
   - **Retry Delay:** `2000 ms`
   - **Reasoning Token Buffer:** `Enabled (Ativo)` *(essencial para modelos que emitem tokens de pensamento)*
   - **Track Metrics:** `Enabled`
6. Clique em **Save / Create Combo**.

---

## 🔍 Registro no Banco Local

Para desenvolvedores que queiram auditar a configuração criada no SQLite (`~/.omniroute/storage.sqlite`):

```bash
sqlite3 ~/.omniroute/storage.sqlite "SELECT id, name FROM combos WHERE name = 'Antigravity-Smart';"
```

Deverá retornar o ID único do combo registrado.
