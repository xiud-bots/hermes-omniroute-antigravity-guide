# 02.2 - Instalação do OmniRoute AI Gateway

O **OmniRoute** (desenvolvido por Diego Souza) é o proxy local que multiplexa conexões de IA e expõe endpoints no padrão universal da OpenAI.

---

## 📋 Pré-requisitos de Runtime
- **Node.js:** Versão 20+ (recomendado Node.js 22 LTS).
- **npm:** Versão 10+.

Verifique as versões atuais:
```bash
node -v
npm -v
```

---

## 📥 1. Instalação Global do Pacote

Execute a instalação através do npm:

```bash
npm install -g omniroute
```

Verifique se o binário está no seu `PATH`:
```bash
which omniroute
omniroute --version
```

*(O executável geralmente reside em `/usr/local/bin/omniroute` ou `$HOME/.local/bin/omniroute`).*

---

## 🏃 2. Inicialização em Modo Interativo

Para validar a primeira execução e realizar a configuração web:

```bash
PORT=20128 omniroute
```

Saída esperada:
```text
  ✨ OmniRoute v...
  🌐 Server listening on http://localhost:20128
  📦 SQLite storage initialized at ~/.omniroute/storage.sqlite
```

> [!NOTE]
> Mantenha esse terminal aberto ou abra uma nova aba para seguir para o próximo passo (autenticação web).
