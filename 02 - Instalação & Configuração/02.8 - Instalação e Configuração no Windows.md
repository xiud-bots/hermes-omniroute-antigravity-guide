# 02.8 - Instalação e Configuração no Windows

Este guia cobre o provisionamento completo do **Hermes Agent + OmniRoute + Google Antigravity** em ambientes **Windows 10 e Windows 11**.

No Windows, existem duas abordagens arquiteturais recomendadas:
1. **Nativa Windows (PowerShell / Windows Terminal):** Ideal para quem utiliza o Hermes Desktop Windows ou CLI diretamente no PowerShell.
2. **WSL2 (Windows Subsystem for Linux):** Ideal para quem deseja paridade 100% com o ambiente Linux (incluindo daemons nativos do `systemd`).

---

## 💻 Abordagem 1: Instalação Nativa no Windows

### 1. Pré-requisitos via Windows Package Manager (`winget`)

Abra o **PowerShell como Administrador** e instale as dependências:

```powershell
# Instalar Node.js LTS (v20+ ou v22+)
winget install OpenJS.NodeJS.LTS

# Instalar Python 3.11
winget install Python.Python.3.11

# Instalar Git para Windows
winget install Git.Git
```

> [!NOTE]
> Feche e reabra o PowerShell após a instalação para recarregar as variáveis de ambiente do `PATH`.

---

### 2. Instalação e Login do Antigravity CLI

1. Instale o pacote do **Google Antigravity IDE** ou adicione o binário `antigravity.exe` ao seu `PATH`.
2. No PowerShell, execute a autenticação:
   ```powershell
   antigravity auth login
   ```
3. O navegador será aberto para autorização com sua conta Google.
4. Os dados serão salvos em: `%USERPROFILE%\.gemini\antigravity-cli\`.

---

### 3. Instalação do OmniRoute no Windows

Instale o pacote globalmente via `npm`:

```powershell
npm install -g omniroute
```

Valide a instalação:
```powershell
omniroute --version
```

Inicie para configuração:
```powershell
$env:PORT=20128
omniroute
```
Acesse `http://localhost:20128` no navegador e configure a conexão `agy` e o combo `Antigravity-Smart` exatamente como nos passos [[02 - Instalação & Configuração/02.3 - Provedor Antigravity no OmniRoute|02.3]] e [[02 - Instalação & Configuração/02.4 - Model Combo Antigravity-Smart|02.4]].

---

### 4. Executando o OmniRoute como Serviço de Background no Windows

No Windows, como o `systemd` não existe nativamente, há três métodos recomendados para manter o OmniRoute ativo no boot:

#### Opção A: Via PM2 (Recomendado — Simples e Estável)
```powershell
# 1. Instalar PM2 globalmente
npm install -g pm2

# 2. Iniciar o OmniRoute na porta 20128
pm2 start omniroute --name omniroute -- --port 20128

# 3. Salvar lista de processos
pm2 save

# 4. Configurar inicialização automática no boot do Windows
npm install -g pm2-windows-startup
pm2-startup install
```

#### Opção B: Via NSSM (Non-Sucking Service Manager)
```powershell
# Instalar NSSM via winget
winget install KirillKovalevsky.NSSM

# Registrar o serviço OmniRoute
nssm install OmniRoute "C:\Program Files\nodejs\node.exe" "C:\Users\<SeuUsuario>\AppData\Roaming\npm\node_modules\omniroute\bin\omniroute"
nssm set OmniRoute AppEnvironmentExtra PORT=20128
nssm start OmniRoute
```

#### Opção C: Script Automatizado em PowerShell
Utilize o script pronto disponível no repositório:
```powershell
.\scripts\setup-omniroute-service.ps1
```

---

### 5. Instalação e Configuração do Hermes Agent no Windows

1. **Instalar o Hermes Agent:**
   No PowerShell, execute o script oficial:
   ```powershell
   irm https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.ps1 | iex
   ```
   *(Ou instale o executável oficial **Hermes Desktop Windows**).*

2. **Configurar o `%USERPROFILE%\.hermes\config.yaml`:**
   Crie ou edite o arquivo de configuração:
   ```yaml
   model:
     default: Antigravity-Smart
     provider: openai-api
     base_url: http://127.0.0.1:20128/v1
     api_mode: codex_responses

   delegation:
     model: Antigravity-Smart
     provider: openai-api
     base_url: http://127.0.0.1:20128/v1
     max_iterations: 250

   terminal:
     backend: local
     timeout: 180
   ```

   > [!WARNING]
   > **Atenção ao salvar o `config.yaml` no Windows:**
   > Salve sempre com codificação **UTF-8 sem BOM**. O Bloco de Notas do Windows costuma salvar em UTF-8 com BOM por padrão, o que causa o erro `HTTP 400 "No models provided"`. Use o VS Code ou o comando `hermes config edit`.

3. **Injetar a Chave de API no `%USERPROFILE%\.hermes\.env`:**
   ```powershell
   Add-Content -Path "$HOME\.hermes\.env" -Value "OPENAI_API_KEY=sk-sua-chave-do-omniroute"
   ```

## 🐧 Abordagem 2: Instalação via WSL2 (Paridade Linux Total)

Se você utiliza o **WSL2** (Ubuntu/Debian no Windows 11/10):

1. **Habilitar o Systemd no WSL2:**
   Edite `/etc/wsl.conf` dentro da sua distribuição WSL:
   ```ini
   [boot]
   systemd=true
   ```
2. No PowerShell do Windows, reinicie o subsistema:
   ```powershell
   wsl --shutdown
   ```
3. Abra sua distro WSL e siga exatamente os passos Linux deste guia:
   - [[02 - Instalação & Configuração/02.2 - OmniRoute AI Gateway|02.2 - Instalação do OmniRoute]]
   - [[02 - Instalação & Configuração/02.6 - Daemon Systemd de Usuário|02.6 - Provisionamento do Serviço Systemd]]
   - [[02 - Instalação & Configuração/02.7 - Configuração do Hermes Agent|02.7 - Configuração do Hermes Agent]]

> [!TIP]
> **Interoperabilidade de Rede no WSL2:**
> O Windows e o WSL2 compartilham o localhost na maioria das versões modernas (modo de rede espelhada `networkingMode=mirrored` em `.wslconfig`). O endpoint `http://127.0.0.1:20128/v1` funcionará de forma transparente tanto de dentro do WSL quanto de aplicativos Windows.

## 🎯 Peculiaridades do Hermes no Windows (Dicas de Sobrevivência)

| Cenário | O que acontece | Como resolver |
| :--- | :--- | :--- |
| **Quebra de linha no Chat** | O Windows Terminal intercepta `Alt + Enter` para alternar tela cheia. | Use **`Ctrl + Enter`** para inserir nova linha sem enviar a mensagem. |
| **Erro UTF-8 BOM no config** | Erro `HTTP 400: No models provided`. | Salve `config.yaml` em **UTF-8 sem BOM** (use `hermes config edit`). |
| **Separação de Pastas** | Barras invertidas (`\`) causam escape no YAML. | Utilize barras normais (`/`) mesmo no Windows (ex: `C:/Users/nome/...`). |
| **Terminal Tool** | O Hermes utiliza internamente `bash` (Git Bash) quando instalado. | Instale o Git for Windows para que ferramentas de terminal funcionem com sintaxe POSIX. |
