# 02.1 - Instalação do Google Antigravity CLI

O **Google Antigravity** é o ambiente que conecta sua máquina ao ecossistema Gemini avançado com suporte a agentes de software.

---

## 📥 1. Instalação do Binário

O Antigravity pode ser instalado através do pacote do instalador oficial do Google ou através do Antigravity IDE:

1. Baixe o pacote para o seu sistema operacional (Linux `.deb` / `.tar.gz` ou macOS `.dmg`).
2. Adicione o executável ao seu `PATH` caso tenha instalado manualmente em diretório isolado:
   ```bash
   export PATH="$HOME/.gemini/antigravity-cli/bin:$PATH"
   ```

---

## 🔑 2. Autenticação Inicial via Conta Google

Execute o comando de login no seu terminal:

```bash
antigravity auth login
```

- Um link de autenticação OAuth do Google será aberto no seu navegador padrão.
- Autorize com a sua conta Google corporativa ou pessoal que possui acesso ao Gemini.
- Ao concluir, o terminal confirmará o salvamento da sessão.

---

## 🔍 3. Verificação de Saúde do Ambiente

Confirme se o diretório de estado e credenciais foi criado com sucesso:

```bash
ls -la ~/.gemini/antigravity-cli/
```

Deverão existir arquivos como:
- `installation_id`
- `settings.json`
- `history.jsonl`
- `cache/` e `log/`

> [!CHECK]
> **Pronto:** Com o Antigravity autenticado e funcional, podemos partir para a instalação do **OmniRoute** para expor esses modelos via API.
