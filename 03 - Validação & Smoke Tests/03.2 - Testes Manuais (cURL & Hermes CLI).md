# 03.2 - Verificação Manual via cURL e CLI

Caso você prefira auditar ou debugar a integração passo a passo de forma isolada, utilize os comandos manuais abaixo.

---

## 1. Teste de Catálogo de Modelos (cURL)

```bash
curl -s http://127.0.0.1:20128/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | jq .
```

*Verifique se o array `data` contém os modelos registrados e o combo `Antigravity-Smart`.*

---

## 2. Teste de Inferência Direta sem Streaming (cURL)

```bash
curl -X POST http://127.0.0.1:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "Antigravity-Smart",
    "messages": [
      {"role": "user", "content": "Explique o que é a constante gravitacional em uma frase."}
    ],
    "max_tokens": 50
  }' | jq .
```

Saída esperada:
```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1793400000,
  "model": "Antigravity-Smart",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "A constante gravitacional universal (G) é uma constante física empírica que mede a intensidade da força gravitacional entre corpos com massa."
      },
      "finish_reason": "stop"
    }
  ]
}
```

---

## 3. Teste Interativo via Hermes CLI

Teste uma consulta rápida não interativa:
```bash
hermes chat -q "Quem é você e qual motor está ativo?"
```

Ou abra uma sessão interativa:
```bash
hermes
```
Dentro da sessão interativa, execute `/status` para inspecionar os detalhes do modelo e da conexão.
