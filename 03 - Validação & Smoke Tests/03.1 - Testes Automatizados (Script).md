# 03.1 - Execução do Script de Smoke Test

Para garantir que toda a cadeia de integração esteja perfeitamente operacional (porta HTTP, modelos, inferência do combo e resposta do Hermes), disponibilizamos o script `scripts/test-omniroute-hermes.sh`.

---

## 🏃 Como Executar

Na raiz deste repositório/vault, execute:

```bash
./scripts/test-omniroute-hermes.sh
```

---

## 🔬 Etapas Validadas pelo Script

1. **Checagem de Porta HTTP (`20128`):** Valida se o daemon do OmniRoute está respondendo a conexões TCP locais.
2. **Consulta ao Catálogo de Modelos (`GET /v1/models`):** Verifica se a chave `OPENAI_API_KEY` tem permissão para listar os recursos e se `Antigravity` está presente.
3. **Inferência Direta via cURL:** Envia um payload sintético ao combo `Antigravity-Smart` e valida se a resposta esperada (`TESTE_OK`) é retornada com sucesso.
4. **Execução no Hermes Agent CLI:** Dispara uma pergunta de identificação ao Hermes CLI (`hermes chat -q`) e imprime o balão de resposta gerado pelo agente.
